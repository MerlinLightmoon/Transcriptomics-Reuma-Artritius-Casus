Het beheren van de data is belangrijk voor het onderzoek. Hierdoor wordt het onderzoek beter reproduceerbaar en leesbaarder voor de lezer. Data overzichtelijk en gestructureerd opslaan is daarom cruciaal. Daarom zijn alle aparte overzichtelijke mapjes opgeslagen. Ook zijn de figuren apart opgeslagen in hun eigen mapje. Ook is in de README alle packages benoemd + de gebruikte versie, zodat het voor de lezer makkelijker te volgen is hoe die het kan reproduceren.

De scripts zijn zelf ook zo overzichtelijk mogelijk gemaakt. Eerst worden de working directory, environment en packages meteen bovenaan klaargezet. Vervolgens worden alle onderdelen van het script duidelijk in aparte koppen verdeeld, en wordt er bij stukken code uitgelegd wat er wordt gedaan. Voor het bewaren en delen van dit onderzoek is GitHub gebruikt. Dit is een website waar veel open-sourceprojecten op staan om te delen met anderen en is veilig en betrouwbaar om te gebruiken. Ook kunnen de scripts altijd op privé gezet worden.
